# SafexAI: Industrial Safety, Reimagined — Zero Harm, Zero Compromise

**ET AI Hackathon 2026 | Problem Statement #1**  
**AI-Powered Industrial Safety Intelligence Platform**

An intelligent multi-agent system that fuses IoT sensors, permits, CCTV, and historical data to detect **compound risks** in real-time and prevent industrial accidents before they happen.

- **Digital Permit Intelligence Agent**
- **RAG-powered Incident Pattern Intelligence**

- **PPE Detection via Computer Vision**
